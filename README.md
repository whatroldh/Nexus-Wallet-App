# Nexus Wallet

نظام محفظة ذكي مصمم للتطبيقات المحمولة، يدعم محاكاة الإيداع والسحب والتحويل بين الحسابات مع واجهة عربية RTL مناسبة للهواتف المحمولة.

## الوصف

هذا المشروع عبارة عن واجهة محفظة إلكترونية (Wallet UI) تعرض:

- رصيد محفظة ثابت أولياً
- تحويل مباشر إلى حساب آخر
- طلب استلام
- إيداع مال
- سحب مال
- إعادة ضبط النظام
- حفظ البيانات محلياً في المتصفح
- دعم تثبيت التطبيق على الهاتف (PWA)

## المميزات

- تصميم عربي كامل مع اتجاه RTL
- متوافق مع الهاتف المحمول
- دعم أندرويد كـ Progressive Web App
- حفظ الرصيد محلياً باستخدام `localStorage`
- رسائل نظام (System Log)
- واجهة بسيطة وسريعة

## التشغيل المحلي

1. افتح مجلد المشروع.
2. قم بتشغيل خادم محلي، مثل:

```bash
python -m http.server 8000
```

3. اذهب إلى العنوان التالي في المتصفح:

```text
http://localhost:8000
```

## تثبيت التطبيق على Android

1. افتح الموقع في متصفح Chrome على الهاتف.
2. اضغط على زر القائمة.
3. اختر "Add to Home screen" أو "تثبيت التطبيق".
4. سيتم تثبيت التطبيق بشكل مشابه للتطبيق الأصلي.
